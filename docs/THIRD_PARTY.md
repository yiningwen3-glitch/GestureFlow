# 第三方组件与许可证

## 运行时组件

- Microsoft .NET Runtime 提供 .NET 10 的运行环境。
- Microsoft .NET Desktop Runtime 包含应用界面使用的 WPF 和系统托盘使用的 Windows Forms。
- Desktop 的界面图标使用 Windows 提供的 Segoe Fluent Icons 字体。应用通过系统 API 访问 Windows 功能。

.NET Runtime 和 .NET Desktop Runtime 的包均随附 .NET Foundation and Contributors 的 MIT 许可证。运行时附带的第三方内容适用各自的条款，详见配套声明。

## 离线查阅声明

从便携包运行时，「关于软件」的文档列表会显示随该包提供的运行时许可证和第三方声明。原件保存在便携包根目录的 `licenses` 文件夹。

从源码构建并使用本机 .NET 时，文档列表会在可读取的情况下显示本机 .NET 安装目录提供的许可证和声明。

GestureFlow 自身的许可状态在「GestureFlow 项目许可证」中单独显示。
