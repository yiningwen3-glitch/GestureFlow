# GestureFlow 隐私声明

Desktop 在本机读取安装注册表、开始菜单、应用包清单以及窗口与进程信息，用于展示应用和判断手势是否可用。目标进程的完整性级别用于即时判断输入是否放行。GestureFlow 不上传应用列表，不读取剪贴板，不把真实按键内容或完整鼠标轨迹写入文件。真实手势的临时坐标与事件队列用于当前输入处理。

应用策略、手动应用清单、共享手势、紧急暂停热键、引导完成状态、主题、关闭行为和灵敏度存放在当前用户的 `%LOCALAPPDATA%\GestureFlow` 下。应用授权凭据由 Windows 用户级数据保护单独保存。快捷键录制保存用户选定的组合键。可执行文件的卷号、文件 ID、大小和时间元数据用于识别应用安装变化。开始菜单和开机启动快捷方式只有在用户主动选择时才会添加。

配置备份由用户选择保存位置，包含已保存的手势和界面设置。真实应用清单、授权、开机启动和引导状态保留在本机。

Lab 的模拟应用授权保存在内存中。用户主动保存的 Lab 配置和测试用例位于用户选择的位置，测试用例包含模拟输入和配置快照。

退出 Desktop 与 Lab 后，可以删除上述本地目录以清除 Desktop 数据。用户主动导出的文件可在各自的保存位置删除。
