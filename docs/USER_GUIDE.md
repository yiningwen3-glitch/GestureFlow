# GestureFlow 使用指南

## 启动和导航

在 Windows 11 x64 上，从便携包运行 `Desktop\GestureFlow.Desktop.exe`。从源码运行时，先安装 .NET 10 SDK，并在仓库根目录执行：

```powershell
dotnet build GestureFlow.sln -c Release
dotnet run --project .\GestureFlow.Desktop -c Release --no-build
```

安装器默认勾选创建桌面快捷方式，并添加开始菜单入口。完成页可直接启动。首次启动可以选侧键、练习拖动，再进入桌面或应用页。练习只显示结果。可以跳过，也可从「设置 → 新手教程」重新打开。

主窗口有「首页」「笔势」「应用」「设置」四个入口。首页显示侧键、启用状态和桌面轮盘。用「试用手势」打开输入测试窗口。右上角的外观选择会在下次启动时恢复。在「设置」选择「添加到开始菜单」后，可在 Windows 开始菜单搜索 GestureFlow。移动程序目录后可再次添加以更新目标。重复启动会唤回已有主窗口。

首次关闭主窗口时，可选择隐藏到托盘、退出软件或取消。所选关闭行为可在「设置」中更改。隐藏时，已开启的手势继续生效。可双击托盘图标或选择「打开 GestureFlow」打开主窗口。托盘「退出」会结束程序和手势监听。最小化后可从任务栏返回。

## 使用悬浮岛

- 从设置页的「悬浮控制岛」或托盘菜单显示悬浮岛。点击胶囊展开，拖动左侧把手调整位置。移动完成后会保存位置，可在设置中恢复默认位置。
- 展开后可为当前应用选用专属方案，或选「使用通用配置」。未启用的应用会将所选方案标注为待用。可在「应用管理」中启用侧键笔势。
- 「完整设置」打开主窗口。隐藏悬浮岛后可从托盘重新显示，手势继续按原运行状态处理。托盘「退出」会同时关闭主窗口、悬浮岛和输入监听。
- 设置页可调整置顶、不透明度、显示时默认折叠和指针离开后自动收起。Lab 的「悬浮岛」页提供虚拟应用和手势预览。

## 先在 Lab 练习

从「设置 → 帮助与工具」打开 GestureFlow Lab。在画布上按住鼠标左键模拟侧键，拖向目标方向后松开即可查看执行结果。可在中心松开、按 Esc 或失去鼠标捕获来取消。

Lab 的「虚拟应用」可切换虚拟前台应用、挑选已保存的方案并模拟执行。点击「重新加载已保存方案」可读取 Desktop 保存的修改。Lab 的「设置」也可以导出笔势 JSON，在 Desktop 的「笔势 → 更多方案」中选择「导入」，然后选用导入的方案。

## 配置桌面手势

1. 打开「笔势」，点击轮盘或列表中的方向。可以直接修改动作名称、快捷键或方向数。
2. 点快捷键录制同时按下的组合，或点「编辑…」直接输入。选「依次按」时每行填写一步，可添加、删除和调整顺序。
3. 点「保存配置」应用修改。首次修改系统默认方案会自动保存为自定义桌面方案。在「应用」点某个软件的「自定义」，也可从桌面配置开始编辑并保存为专属方案。

从「更多方案」可复制、切换、导入或导出方案。

「恢复默认选用」会让通用范围使用系统默认方案，或让当前应用跟随通用方案。「还原此方案的默认绑定」只改变编辑器中的草稿，保存后应用。应用启用后，先使用有效的专属方案，再回退到当前通用方案，最后回退到系统默认方案。

## 登录启动、灵敏度和备份

- 勾选「登录 Windows 时启动 GestureFlow」为当前用户登记启动快捷方式。下次登录时打开主窗口并启用桌面手势。移动程序目录后，可取消勾选再重新勾选来更新路径。Windows 的启动应用设置也会影响是否执行。
- 在「轮盘灵敏度」选择高、标准或低，对应至少移动 16、24 或 40 个设备无关单位。此设置适用于 Desktop 的真实手势、输入测试窗口和轮盘预览。
- 「备份配置」保存当前通用方案、暂停热键、灵敏度、主题和关闭行为。其他方案可在「配置方案管理」中分别导出。应用授权、开机启动选项和首次使用状态由本机单独管理。
- 「恢复配置」会应用备份中的偏好、从备份创建并选用通用方案，并关闭输入监听。需要继续使用真实手势时，请回到首页重新开启。

升级时若提示旧配置迁移失败，可在 `%LOCALAPPDATA%\GestureFlow` 查找旧文件及 `.pre-v1.1.bak` 备份。可读的独立手势 JSON 可从方案管理页导入，可读的合并配置可从设置页恢复。若方案目录损坏，程序会使用其余可读方案或系统默认，下一次保存前会把原目录文件保留为 `.recovery` 文件。

## 使用真实手势

1. 切到 Windows 桌面，按住所选鼠标侧键并向目标方向拖动，在目标方向松开即可执行通用方案中的动作。
2. 要在应用内使用，在「应用管理」中找到目标应用，核对身份和路径，再点击「启用笔势」。页面顶部的「Windows 桌面」可直接打开通用笔势配置。应用列表显示有桌面快捷方式的应用，以及 Word、Excel、PowerPoint 等已安装的 Microsoft Office 软件。方案管理沿用同一范围。在「设置 → 鼠标侧键」选择鼠标侧键 1 或 2。所选侧键适用于桌面、已启用应用和输入测试窗口。
3. 启用后在该应用详情点击「开启应用内笔势」。可使用首页、托盘或紧急热键暂停。默认热键为 Ctrl + Shift + F10，可在关闭监听后前往「设置」更改。

真实输入及应用授权的边界见 [安全说明](SAFETY.md)。常见操作和故障排除见 [常见问题](FAQ.md)。
