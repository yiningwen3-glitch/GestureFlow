# GestureFlow 安全说明

## 应用保护

- Desktop 启动时默认启用 Windows 桌面的侧键按住并拖动的手势。应用内使用需要在应用详情启用笔势，并打开全局输入。
- 手势授权绑定应用身份、本地可执行文件及其安装标识。未授权、身份不明或安装标识无法核对时，原生输入放行。程序更新、重装或移动后可能需要重新授权。
- 在应用详情核对程序路径后，点击「启用笔势」。更换安装后可刷新清单并重新启用。
- 被接管的侧键按下和释放会成对拦截，避免触发浏览器前进或后退。暂停后，下一次侧键按下恢复原生行为。右键事件直接交给系统和应用。
- Desktop 在接管手势和发送前核对窗口及焦点所属进程的完整性级别。目标级别更高或无法核对时，原生输入保持放行。发送快捷键前也会检查目标窗口、焦点、授权和物理按键。前台切换、暂停或授权失效时取消在途操作。
- 怀疑有冲突时按 Ctrl + Shift + F10 暂停，或从托盘关闭手势监听。要撤销单个应用的授权，可进入其应用详情。应用管理页的「停用所有应用笔势」会关闭监听并撤销所有应用授权。
- 隐藏到托盘后，已开启的手势继续生效。退出程序会关闭监听。测试窗口关闭时会关闭测试监听。
- 登录启动按正常启动流程保持输入关闭。恢复配置备份也会停止监听，真实应用授权仍由独立的授权存储管理。
- Lab 的模拟快捷键和虚拟应用启用状态在 Lab 内运行。需要验证真实监听时，先使用 Desktop 的独立输入测试窗口。

## 使用须知

可在「设置 → 鼠标侧键」切换用于触发笔势的侧键。

完整验证范围见 [兼容性说明](COMPATIBILITY.md)。
