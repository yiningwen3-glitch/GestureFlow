# Windows 11 兼容性与验证范围

## 安全默认值

Desktop 启动时默认启用 Windows 桌面的侧键按住并拖动的手势。应用内使用需要单独授权并开启全局输入。紧急暂停保留授权，一键恢复默认保护会关闭监听并撤销全部授权。睡眠、恢复或任务栏重建通知会关闭监听，恢复使用时须手动开启。

安装标识来自本地可执行文件的 Windows 卷号、文件 ID、大小和时间元数据。修改、重装或更新可能要求重新授权。文件不可读、远程路径或文件系统无法提供稳定标识时，输入保持放行。此标识用来区分安装替换。

## 鼠标行为

| 场景 | 当前行为与边界 |
| --- | --- |
| 右键 | 点击、长按和拖放交给系统和应用。 |
| 同时按住多个鼠标按钮 | 触发前已有其他物理鼠标按钮按住时放行。已捕获后再按其他键会取消手势，被捕获的原始按下通常无法补回。 |
| 鼠标侧键 | 所选侧键的原生前进或后退操作可能被占用。 |
| 焦点丢失 | 取消在途手势和排队命令。Windows 焦点检查和输入发送之间存在系统调度间隔。 |
| 混合 DPI | 以按下显示器 DPI 换算位移，轮盘约束到工作区。跨显示器仍使用起始屏幕的比例。 |
| 高权限窗口 | Desktop 在接管及发送前核对窗口和焦点所属进程的完整性级别。目标级别更高或无法核对时保留原生输入。 |

## 隐私

已安装应用发现使用本机只读来源。本软件不上传应用列表、不读取剪贴板，也不写入真实键盘内容或完整鼠标轨迹。真实手势的临时坐标和事件队列只用于当前输入处理。快捷键录制只在用户主动录制时处理按键，保存的是选定的快捷键绑定。Lab 可由用户主动保存虚拟测试用例，其中只包括模拟输入。

## 验证边界

自动化与 Windows 实机检查记录见 `PROGRESS.md`。当前已在单屏 144 DPI 上验证轮盘边缘位置和低完整性进程向中完整性目标发送输入时的保护。实体鼠标、混合 DPI 双屏、普通权限 Desktop 与管理员目标组合，以及真实睡眠和资源管理器重启仍需现场验证。

## 现场验证步骤

先关闭全局输入。在首页打开「输入测试窗口」，使用测试编辑框和可丢弃文本。在「设置 → 鼠标侧键」选择要验证的侧键，再选择「仅为此窗口启用」。通过后再选一个明确的真实应用验证逐应用授权。

| 场景 | 操作及预期 |
| --- | --- |
| 右键与侧键 | 分别选用侧键 1 和侧键 2。普通右键应打开编辑框菜单。按住所选侧键应出现轮盘，拖向目标方向并松开后执行。 |
| 暂停和切换 | 开始拖动后切换前台，或使用当前设置的暂停热键。轮盘应取消，快捷键不应送到原窗口或新窗口。关闭测试窗口后，监听应停止。 |
| 混合 DPI 双屏 | 使用两台不同缩放的显示器，把测试窗口移到两侧的工作区边缘各触发一次，再保持焦点不变，按下后向另一屏拖过边界。核对轮盘留在起始屏幕工作区、方向命中正确、识别距离按起始屏幕 DPI 换算。 |
| 管理员目标 | 在隔离的同账号测试会话，用普通权限运行 Desktop，以管理员身份运行空白测试编辑器并完成该编辑器的授权。核对目标原生右键仍可用，手势轮盘和快捷键均未触发。完成后关闭全局输入并解除测试授权。 |
| 系统状态变化 | 在隔离会话仅启用输入测试窗口，分别进行真实睡眠唤醒和资源管理器重启。核对监听状态回到关闭，可从现有界面手动开始下一轮。 |

记录 Windows 版本、显示器缩放、触发方式、目标窗口权限和实际结果。
