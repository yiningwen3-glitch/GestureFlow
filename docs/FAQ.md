# GestureFlow 常见问题

### 启动后为什么没有真实手势？

启动后，在 Windows 桌面按住所选鼠标侧键拖向目标方向，松开后即可执行手势。要在应用内用手势，先启用目标应用的手势并从首页开启全局输入。也可在输入测试窗口练习。

### 为什么应用找不到，或无法配置并启用？

已安装的 Word、Excel 等 Microsoft Office 应用会自动列出。其他程序可通过个人或公共桌面上的快捷方式加入。点「刷新应用」并清除筛选。启用需要可核对的应用身份和本地安装标识。

### 为什么启用后又失效？

应用重装或路径变化后，侧键笔势可能需要重新启用。刷新应用清单，核对当前安装后点击「启用笔势」。

### 为什么轮盘预览已变化，桌面手势仍使用旧动作？

「笔势」中的改动先更新预览。编辑当前使用的方案后，点击「保存配置」立即应用。通过「更多方案」编辑其他方案时，可手动选用。显示名称为空白时无法保存，请先修改对应名称。只按 Esc 可退出快捷键录制，部分由 Windows 拦截的组合键可能无法在窗口内录下。

### 侧键笔势或快捷键出现异常怎么处理？

先暂停或关闭输入，核对前台窗口、应用授权和触发方式。可以在「设置 → 鼠标侧键」切换侧键 1 或侧键 2。前台应用的完整性级别更高或无法核对时，GestureFlow 会保留原生输入。详见 [安全说明](SAFETY.md)。

### 为什么打开 Lab 失败？

便携版需要保留与 Desktop 并列的 Lab 目录。从源码运行时，先构建整个解决方案，确保 Desktop 与 Lab 使用相同的构建配置。

### 为什么关闭窗口后 GestureFlow 还在运行？

选择「隐藏到托盘」时，程序仍在后台运行。在托盘菜单选择「退出」即可结束程序，也可在「设置」将关闭行为改为「退出软件」。

### 怎样从开始菜单打开 GestureFlow？

先在 Desktop 的「设置」选择「添加到开始菜单」，然后在 Windows 开始菜单搜索 GestureFlow。如果移动了程序目录，从新位置打开 Desktop 并再次添加。

### 恢复备份后为什么需要重新开启手势？

配置恢复会关闭输入监听。原有真实应用授权仍然有效时，可回到首页重新开启全局输入。

### 如何离线查看使用说明和隐私声明？

在「使用帮助」查看 [使用指南](USER_GUIDE.md)、[安全说明](SAFETY.md) 和本文。在「关于软件」查看 [隐私声明](PRIVACY.md)、更新日志和许可证。
